## Что нашли в ходе аудита

### Структура проекта

Текущий сервис реализует:

**Основные задачи:**
- `LIST_FROM_GRAND` — извлечение перечня работ/материалов из Гранд-сметы (Excel, чанкинг + resume)
- `LIST_FROM_PROJECT` — извлечение перечня из проектной документации (PDF, один запрос)

**Подзадачи (запускаются кнопкой из карточки задачи):**
- `CHECK_LIST_COMPLETENESS` — проверка полноты перечня из Гранд-сметы по ГЭСН
- `CHECK_PROJECT_COMPLETENESS` — проверка полноты перечня из проекта по ГЭСН

**Прочее:**
- Калькулятор площадей помещения (`/calculator`)
- Проекты (группировка задач)
- Панель администратора
