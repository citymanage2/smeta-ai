# Онлайн-редактор для задач перечня (LIST_FROM_GRAND, LIST_FROM_PROJECT)

## Задача

В TaskStatus.tsx для задач типа `LIST_FROM_GRAND` и `LIST_FROM_PROJECT` со статусом `completed` добавить карточку «Перечень готов — редактор доступен» с кнопкой «Открыть редактор →», аналогично тому, как это сделано для `ESTIMATE_OPTIMIZATION`.

Редактор (страница `/tasks/:taskId/estimate`) уже полностью поддерживает эти типы через `GenericGrid` с вкладками, undo/redo и сохранением — нужно только добавить точку входа из страницы задачи.

## Фазы

- [x] Фаза 1: Добавить карточку «Открыть редактор» в TaskStatus.tsx для LIST_FROM_GRAND и LIST_FROM_PROJECT

## Итог

Реализовано целиком. В TaskStatus.tsx добавлен блок между секцией «Результаты» и карточкой «Проверки полноты». Кнопка открывает `/tasks/${taskId}/estimate` — EstimateOptimizer автоматически определяет тип задачи, инициализирует версию из результата и показывает GenericGrid.
