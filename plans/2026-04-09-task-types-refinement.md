## Контекст

Все старые промпты и типы задач удалены (2026-04-09). Начинаем с чистого листа — добавляем по одному типу задачи за раз.

Промпты живут в `backend/app/services/task_processor.py`. Каждый тип задачи — отдельный обработчик `_handle_*`.

**Цель плана:** итеративно добавлять типы задач: промпт → тест → деплой → следующий.

**Реализованные типы задач:**

---

## Принцип работы

Один тип задачи за раз:

```
Спек типа задачи
→ Тест-кейсы (реальные файлы)
→ Запуск в системе
→ Анализ результата
→ Рефайн промпта
→ Повторный тест
→ Фиксация (документация + деплой)
→ Следующий тип
```

## Шаблон рабочей сессии (для каждого типа задачи)

При начале работы над конкретным типом задачи:

```
1. Прочитай спек из docs/task-types/<тип>.md
2. Прочитай текущий промпт из backend/app/prompts/<тип>.py
3. Запусти тест через tests/run_prompt_test.py
4. Проанализируй расхождение с эталоном
5. Исправь промпт
6. Повтори 3–5 пока качество не достигнет цели
7. Обнови спек если нужно
8. Задеплой (push → Render)
9. Проведи ручной тест
10. Отметь фазу как [x] в этом плане
```
