# Ограничение размера изображений для Claude Vision (≤8000 px)

## Проблема

Claude Vision API отклоняет изображения, у которых любая сторона > 8000 px:
`400 invalid_request_error: image dimensions exceed max allowed size: 8000 pixels`.

Падение возникает на чертежах/сметах большого формата (A1/A0, длинные «простыни»),
отрендеренных из PDF при `dpi=200`, а также на крупных пользовательских сканах,
которые отправлялись в модель без проверки размеров.

## Источники картинок без ограничения

- `backend/app/utils/pdf_text_extractor.py` — `extract_pdf_hybrid` и `chunk_project_pdf`
  рендерят страницы через `page.get_pixmap(dpi=200)`.
- `backend/app/utils/file_parser.py` — `file_to_base64` отправляет загруженное изображение как есть.

## Решение

Лимит с запасом: `MAX_IMAGE_DIMENSION = 7500` px.

### Фаза 1 — рендер PDF [x]
- [x] Хелпер `_render_page_png(page, dpi=200, max_px=7500)`: вычисляет scale-матрицу так,
      чтобы максимальная сторона не превышала лимит; возвращает PNG-байты.
- [x] Использовать его в `extract_pdf_hybrid` и `chunk_project_pdf`.

### Фаза 2 — загруженные изображения [x]
- [x] В `file_to_base64` даунскейлить через Pillow, если сторона > 7500 px,
      с сохранением пропорций; для не-PNG/JPEG форматов — без изменений.

## Итог

Реализовано целиком. Оба источника изображений теперь не превышают лимит API.
