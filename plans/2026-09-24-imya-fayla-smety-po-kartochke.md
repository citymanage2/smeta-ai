# Имя файла сметы и оптимизации — по карточке

**Зачем.** Все сметы проекта скачивались как «Смета_из_перечня.xlsx», оптимизация —
как «optimized.xlsx». В загрузках их не различить. Теперь имя повторяет часть
названия карточки после двоеточия: «Перечень из Гранд-сметы: ПОМЕЩЕНИЯ_№_93» →
«Смета_ПОМЕЩЕНИЯ_№_93.xlsx», «Оптимизация_ПОМЕЩЕНИЯ_№_93.xlsx».

## Фазы

- [x] Помощник `backend/app/services/result_names.py`: отличительная часть названия
      карточки, безопасное имя файла, поиск карточки по задаче любого этапа.
- [x] Смета: файл расчёта (`task_processor._handle_estimate_from_list`) и рабочий
      файл слота `estimate` (`estimate_store._store_estimate_file`). Старое запасное
      имя «Смета_из_перечня.xlsx» меняется на новое при следующей записи; имя,
      которое дал человек, не трогается.
- [x] Оптимизация: слот `optimized` (`tasks._run_optimization_background`) и выгрузка версии
      (`estimate_versions.export_version`, фронт берёт имя из `Content-Disposition`).
      Окно `OptimizeModal` качает через `downloadSlotFile`.
- [x] Тесты: `tests/test_result_names.py`.

## Итог

Реализовано целиком. Карточку переименовали — уже созданные файлы остаются со
старым именем (новое получат при пересчёте).
