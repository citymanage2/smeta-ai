# Бланк сводной уезжает в файл целиком

## Задача

При выгрузке сводной в xlsx блок «Себестоимость и цена для заказчика» приезжал
урезанным: у части строк стояла одна сумма вместо двух стоимостей. Нужно, чтобы
в файле были все колонки бланка — и «Стоимость с НДС», и «Стоимость без НДС».

## Что было

Лист «Сводная» строился по своей раскладке, не по экранной:

| Экран | Файл (было) |
|---|---|
| № | — |
| Наименование | «Статья затрат» (колонка A) |
| % / Кол-во | — (проценты приклеивались к названию: «Непредвиденные расходы 2%») |
| Стоимость с НДС | «С НДС» (C) — только у 18 строк расходов и ручных строк |
| Стоимость без НДС | «Без НДС» (B) — там же |

Всё, что ниже итога себестоимости — непредвиденные, прибыль, полная
себестоимость, НДС, др. налоги, итог для заказчика, справочные строки под
итогом — писалось **одной суммой в четвёртую колонку «Сумма»**, а колонки
«с НДС»/«без НДС» у этих строк оставались пустыми. Коэффициент к ценам и
количество разнорабочих в файл не попадали вовсе.

## Что стало

Лист «Сводная» повторяет экран (`components/summary/SummarySheet.tsx`):

```
A: №   B: Наименование   C: % / Кол-во   D: Стоимость с НДС   E: Стоимость без НДС
```

- строка «Коэффициент к ценам» — как на экране, значение в колонке C;
- 18 строк расходов и ручные строки — номер, обе стоимости; проценты
  (транспорт, уборка, накладные) и количество людей — числом в колонке C с
  форматом `3%` / `2 чел`, а не текстом в названии;
- «ИТОГО себестоимость объекта» и «Непредвиденные расходы» — обе стоимости;
- строки с одной суммой (прибыль, полная себестоимость, НДС, др. налоги, итог
  для заказчика) — ячейка D:E объединена, как растянутая ячейка на экране;
- справочные строки под итогом себестоимости — обе стоимости, а не одна.

Таблица разделов сдвинулась на колонку вправо (F → G): слева стало пять колонок
вместо четырёх. Порядок столбцов внутри раздела прежний.

## Фазы

### Фаза 1. Раскладка листа «Сводная» [x]

- `utils/summary_calc.calc_summary` отдаёт ввод человека для колонки
  «% / Кол-во»: `coefficient`, `transport_pct`, `cleanup_pct`, `overhead_pct`,
  `daily_workers_qty`.
- `utils/xlsx_summary._write_summary_sheet` переписан на экранную раскладку;
  helpers `_money`, `_merged_money`, `_input_cell`, `_custom_row`, `_total_row`.
- Таблица разделов: `OFF = 7`.

### Фаза 2. Тесты [x]

- Новый `backend/tests/test_xlsx_summary.py` — раскладка листа на том же наборе
  данных, что у `test_summary_calc.py` (он совпадает с фронтовым регресс-тестом
  до копейки): обе стоимости у строк расходов, ручных и добавленных строк, у
  итога себестоимости и непредвиденных; проценты и коэффициент в колонке C;
  объединённые ячейки у строк с одной суммой; нумерация с учётом скрытых строк;
  «ИТОГО для Заказчика» = 222 647,82 ₽.
- Проверки xlsx убраны из `test_summary_calc.py` — там остались только формулы.

## Итог

Реализовано целиком. Формулы бланка не менялись — числа те же, что на экране;
изменилась только раскладка файла.
