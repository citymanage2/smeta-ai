# Форматирование листа «Перечень» в скачиваемом Excel

## Задача

Унифицировать оформление листа «Перечень» в скачиваемых xlsx-файлах для задач:
- **Перечень из Гранд-сметы** (`generate_list`)
- **Перечень из проекта** (`generate_list_project`)

## Формат листа «Перечень»

### Строки заголовков

| Строка | Содержание | Стиль |
|---|---|---|
| 1 | №п/п \| Тип \| Наименование \| Ед. изм \| Кол-во \| Примечание | Arial 9pt, жирный, чёрный, по центру |
| 2 | 1 \| 2 \| 3 \| 4 \| 5 \| 6 | Arial 9pt, чёрный, по центру |

### Строки данных

**Раздел** (только для generate_list_project):
- Колонка 3: «Раздел N. Наименование» — жирный, по центру, Arial 9pt чёрный
- Остальные колонки: пусто

**Работа**:
- Кол. 1: номер (целое, по центру, чёрный)
- Кол. 2: «Работа» (по центру, чёрный)
- Кол. 3: наименование (по левому краю, чёрный, перенос)
- Кол. 4: ед. изм. (по центру, чёрный)
- Кол. 5: кол-во (по центру, 2 знака, чёрный)
- Кол. 6: примечание (по левому краю, чёрный, перенос)

**Материал**:
- Кол. 1: номер (целое, по центру, чёрный)
- Кол. 2: «Материал» (по центру, #4284F3 курсив)
- Кол. 3: наименование (по правому краю, #4284F3 курсив, перенос)
- Кол. 4: ед. изм. (по правому краю, #4284F3 курсив)
- Кол. 5: кол-во (по правому краю, #4284F3 курсив, 2 знака)
- Кол. 6: примечание (по левому краю, чёрный, перенос)

### Параметры листа

- Границы: тонкий чёрный со всех сторон
- Ширины столбцов (Excel): 6.5 | 10.33 | 67.33 | 10.33 | 10.33 | 57.5
- Колонки 3 и 6: wrap_text=True
- Формат кол. 1: целое (`0`)
- Формат кол. 5: `0.00`

## Реализация

### Файл: `backend/app/services/excel_service.py`

Добавлен хелпер `_write_perechen_sheet(ws, items, with_sections=False)`:
- `with_sections=False` — для `generate_list` (гранд-смета): секций нет
- `with_sections=True` — для `generate_list_project` (из проекта): группирует по полю `section`, вставляет строки-заголовки разделов

Функции `generate_list` и `generate_list_project` обновлены: Sheet 1 «Перечень» теперь строится через `_write_perechen_sheet`.
