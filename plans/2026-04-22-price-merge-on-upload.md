# Слияние прайсов при загрузке нового файла

**Дата:** 2026-04-22  
**Статус:** Реализовано

## Задача

При загрузке нового файла прайса (работ или материалов) существующие данные не удалять, а **объединять** с новыми.

## Фазы

- [x] **Фаза 1: Исследование** — изучить текущую логику `_handle_price_upload` в `admin.py`
- [x] **Фаза 2: Backend — merge вместо delete+insert**
  - Загружаем существующие строки в память по нормализованному имени
  - Для совпадений: UPDATE (works — объединяем dict `prices`, materials — обновляем цену)
  - Для новых: INSERT
  - `price_lists` — upsert (обновляем метаданные без удаления)
  - Ответ: `{loaded, message, added, updated}`
- [x] **Фаза 3: Frontend** — добавить optional поля `added`/`updated` в `SinglePriceUploadResponse`

## Изменённые файлы

- `backend/app/routers/admin.py` — основная логика merge
- `frontend/src/api/admin.ts` — тип `SinglePriceUploadResponse`

## Итог

Реализовано целиком. Теперь при загрузке нового файла:
- Новые позиции добавляются
- Существующие позиции (совпадение по нормализованному имени) обновляются
- Для works — словарь подрядчиков объединяется (новые подрядчики добавляются, цены обновляются)
- Сообщение: «Прайс работ обновлён: добавлено X, обновлено Y позиций»
