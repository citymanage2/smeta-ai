# Редизайн сайдбара

## Задача
Переработать левый сайдбар: новый дизайн по референсу, кнопка скрыть/показать, hover-иконки, улучшенный UX.

## Фазы

### [x] Фаза 1: Layout.tsx — управление состоянием коллапса
- Добавлен `sidebarOpen` state с localStorage-персистентностью
- Добавлен `handleToggleSidebar` и проброс `open` / `onToggle` в `ProjectsSidebar`

### [x] Фаза 2: ProjectsSidebar.tsx — новый дизайн
- Принимает `open: boolean` и `onToggle: () => void`
- Collapsed-режим: 44px полоска с иконками Создать задачу / Проекты + кнопка раскрыть
- Expanded: кнопка «Скрыть» снизу с иконкой ChevronsRight
- Кнопка «Создать задачу» (FileText) рядом с «Новый проект»
- ChevronRight вместо unicode ▶ для раскрытия проектов
- Badge с числом задач заменил число в углу
- ActionBtn с hover-эффектами вместо всегда-видимых иконок

### [x] Фаза 3: CSS hover для task-actions
- Добавлены стили в `index.css`: иконки редактирования/удаления задач показываются только при наведении

## Итог

Реализовано полностью:
- Кнопка скрыть/показать сайдбар (persist в localStorage)
- Collapsed режим с минимальными иконками
- Обновлённый дизайн: белый фон, ChevronRight, badge, ActionBtn с hover
- Hover-only иконки редактирования/удаления (чище, меньше шума)
- Кнопка быстрого перехода к созданию задачи
- Вся существующая функциональность (inline edit, delete) сохранена
