# Удаление карточки канбана вместе с задачами

## Задача
Добавить возможность удалить карточку канбана полностью вместе со всеми связанными задачами. Иконка корзины на карточке, подтверждение через модальное окно.

## Фазы

### [x] Фаза 1: Backend — каскадное удаление задач
- `backend/app/routers/workflow_cards.py` — эндпоинт `DELETE /workflow-cards/{card_id}` собирает все task_id карточки, удаляет задачи (CASCADE чистит TaskResult/TaskInputFile/TaskHistory), затем удаляет карточку.

### [x] Фаза 2: Frontend — UI удаления
- `frontend/src/components/kanban/KanbanCard.tsx` — иконка `Trash2` в заголовке карточки; локальный стейт `showConfirm`; портал-диалог с подтверждением (имя карточки, кнопки «Отмена» / «Удалить»); спиннер «Удаление…» во время запроса.

## Итог
Реализовано полностью. Карточка с корзиной → диалог подтверждения → удаление карточки + всех задач безвозвратно.
