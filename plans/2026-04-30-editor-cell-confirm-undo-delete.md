# Онлайн-редактор: подтверждение ячейки, undo/redo, удаление строк

**Дата:** 2026-04-30

## Задача

Улучшить онлайн-редактор таблицы сметы тремя функциями:
1. Кнопки ✓/✕ в каждой редактируемой ячейке
2. Undo/Redo (отмена/возврат изменений) с кнопками ↩/↪
3. Удаление строк с проверкой связанных материалов

## Фазы

### [x] Фаза 1: Кнопки подтверждения/отмены ячейки

- Новый компонент `ConfirmTextEditor` (для name, unit) с ✓/✕
- Обновлённый `NumberEditor` (qty, price_*) с ✓/✕
- `onMouseDown + e.preventDefault()` на кнопках — чтобы blur не срабатывал до click
- Enter = подтвердить, Esc = отменить (оба через KeyDown)
- Работает на всех вкладках (all/works/materials) и всех этапах оптимизации (тот же редактор)

### [x] Фаза 2: Undo/Redo

**Store (`estimateEditor.ts`):**
- `undoStack: EstimateRow[][]` — стек прошлых состояний (макс. 50)
- `redoStack: EstimateRow[][]` — стек отменённых изменений
- `updateRows` пушит текущий activeRows в undoStack перед заменой, очищает redoStack
- `undo()` — берёт последний из undoStack, текущее кладёт в redoStack, сохраняет через API
- `redo()` — обратная операция
- `deleteRows`, `setActiveVersion`, `reset` — корректно управляют стеками
- MAX_HISTORY = 50 (ограничение памяти)

**UI (`EstimateGrid.tsx`):**
- Пропсы `canUndo`, `canRedo`, `onUndo`, `onRedo`
- Кнопки ↩/↪ в header-баре справа
- Disabled когда стек пуст или isReadonly

### [x] Фаза 3: Удаление строк

**Два режима удаления:**
- "Удалить строку" — удалить только выбранные строки. Если выбранная работа имеет не-выбранные материалы → диалог предупреждения
- "Удалить позицию" — удалить выбранные работы + все их материалы автоматически

**Проверка связанности:** позиционная эвристика — материалы, идущие сразу после работы (до следующей работы/раздела), считаются её материалами (`getMaterialsForWork`)

**Диалог:** Modal-оверлей при наличии связанных материалов:
- Показывает список работ и их материалов (max 4 в группе + "ещё N")
- Три кнопки: "Отмена", "Удалить только работы", "Удалить и материалы тоже"

**Store:** `deleteRows(rowIds)` — фильтрует activeRows, пушит в undoStack (можно отменить удаление через undo)
