# Свёртка одинаковых позиций в общий объём

**Дата:** 13.08.2026
**Статус:** реализован целиком

## Зачем

Одна и та же работа («Штукатурка стен, м2») встречается в чужой смете по пять
раз — в разных разделах, на разных листах, с разными объёмами. Проверить перед
тендером, сколько всего штукатурки в контракте, можно только сложив пять чисел
в уме. И цену приходится править пять раз: пропустил одну позицию — смета
уехала с двумя разными ценами на одну работу, и это не видно никак.

Нужно: одинаковые позиции показывать одной строкой с общим объёмом, а правку
такой строки разносить по всем позициям сразу.

## Решения пользователя (13.08.2026)

1. **Режим показа, а не слияние строк.** Строки документа остаются как есть:
   разделы, листы и «№ в исходной смете» никуда не деваются, файл выгружается
   построчно. Свёртка — взгляд на таблицу, включается кнопкой.
2. **Ключ группы:** тип + наименование + единица измерения, без учёта регистра
   и лишних пробелов. Разные единицы (м2 и м3) не объединяются никогда.
3. **Объём у свёрнутой строки — только чтение.** Общий объём это результат, а не
   ввод. Правится позиционно, в развёрнутой группе.
4. **Совместно правятся:** цена работ, цена материалов, наименование, ед. изм.
5. **Стадии:** все пять — перечень, полнота, смета, версии оптимизации, разделы
   сводной.
6. **Свёртка идёт через все листы сразу**, вкладки листов в этом режиме
   отключаются.
7. **В скачиваемый файл** свёртка попадает только по галочке в конструкторе
   выгрузки; обычная выгрузка остаётся построчной.

## Что считается сделанным (критерии приёмки)

- [x] В редакторе есть переключатель «Свернуть дубли»; состояние живёт в адресе
      страницы (`?collapsed=1`), по ссылке коллега видит то же самое.
- [x] В свёрнутом режиме одинаковые позиции показаны одной строкой: объём —
      сумма, стоимости — сумма стоимостей позиций (а не «сумма объёмов × цена»:
      цены внутри группы могут отличаться).
- [x] Группу можно развернуть и увидеть её позиции с их разделами и объёмами.
- [x] Правка цены/наименования/ед. изм. в свёрнутой строке меняет **все**
      позиции группы; стоимость каждой пересчитывается по её собственному объёму.
- [x] Ячейка объёма у свёрнутой строки не редактируется.
- [x] Поле, значения которого у позиций разошлись (например, разные цены),
      показывается как «разные», а не первым попавшимся числом.
- [x] Итоги внизу и «Применить» работают по настоящим строкам: свёртка не
      меняет ни одной цифры в документе, пока человек ничего не правил.
- [x] Одиночная позиция (дублей нет) выглядит и правится как обычная строка.
- [x] Строки-разделы в группы не собираются.
- [x] В свёрнутом режиме недоступны перетаскивание строк и вставка из буфера —
      с понятной подсказкой, а не молча.
- [x] Выделение свёрнутой строки выделяет все её позиции: удаление, коэффициент
      и работа с прайсом получают настоящие ключи строк, а не ключ группы.
- [x] В конструкторе выгрузки есть галочка «Свернуть одинаковые позиции».
- [x] Работает во всех пяти типах документов; в перечне без колонки
      «Наименование» кнопка недоступна и объясняет почему.

## Границы (чего не делаем)

- Не сводим единицы измерения между собой (т↔кг): «т» и «кг» — разные группы.
  Сводимость единиц — правило подбора цены (`unit_compat`), к показу отношения
  не имеет, и молча сложить тонны с килограммами в один объём нельзя.
- Не удаляем дубли и не склеиваем строки физически.
- Не трогаем backend: ни один эндпоинт, ни одна модель не меняются.

## Как устроено

### Ядро — `frontend/src/components/editor/collapse.ts`

Чистые функции над списком строк таблицы, без React:

- `collapseKey(adapter, row, fields)` — ключ группы или `null` (раздел, пустое
  наименование);
- `buildCollapsedRows(rows, fields, expanded)` — строки для показа: групповая
  строка на месте первой позиции группы, под ней — её позиции, если группа
  раскрыта; группа из одной позиции остаётся обычной строкой;
- `spreadEdit(groupRow, changedKey, members, fields)` — правка групповой строки
  → правки всех её позиций.

Служебные поля групповой строки (`__group`, `__mixed`, `__child`) начинаются с
`__`, поэтому в документ не попадают: оба адаптера служебные ключи отбрасывают.

### Что адаптер сообщает о своих колонках

`EditorAdapter` получает необязательный метод
`collapseFields(columns): CollapseFields | null`:

```
{ nameKey, unitKey, kindOfRow, sharedKeys, sumKeys }
```

- смета: `name`, `unit`, общие — `name/unit/price_work/price_material`,
  суммируемые — `qty/cost_work/cost_material`;
- перечень и полнота: колонки опознаются по названиям из файла заказчика теми же
  ключевыми словами, по которым уже работает пересчёт «цена × объём». Нет
  колонки «Наименование» — метод возвращает `null`, режим недоступен.

### Почему свёртка — уровень показа

`rows` в сторе остаются настоящими строками документа. Свёртка применяется
только к `displayedRows`, поэтому «Применить», итоги, история, откат, черновик,
журнал корректировок и присутствие продолжают работать ровно как раньше. Правка
через групповую строку — это N обычных правок N строк, и в журнал корректировок
она уедет как N расхождений «система посчитала X — человек поставил Y».

## Фазы

### Фаза 1 — ядро свёртки [x]
- `collapse.ts` + `collapseFields` в обоих адаптерах.
- Тесты: ключ группы (регистр, пробелы, разные единицы, разный тип), суммы
  объёмов и стоимостей точными числами, «разные» при расхождении, группа из
  одной строки, разделы не сворачиваются, разнос правки по позициям.

### Фаза 2 — режим в редакторе [x]
- Кнопка в тулбаре, состояние в адресе, отключение вкладок листов.
- Показ групп, раскрытие/сворачивание, «разные» в ячейке, отступ у позиций.
- Правка групповой строки разъезжается по позициям; объём не редактируется.
- Итог в свёрнутом режиме — по всему документу.

### Фаза 3 — безопасность операций [x]
- Выделение группы = выделение её позиций.
- Перетаскивание и вставка из буфера в свёрнутом режиме отключены с подсказкой.
- Тесты на то, что ключ группы не утекает в удаление и в действия с прайсом.

### Фаза 4 — свёртка в выгрузке [x]
- Галочка в конструкторе выгрузки, свёртка строк выгрузки теми же правилами.
- Тест: в файл уходит одна строка с общим объёмом и суммой стоимостей.

### Фаза 5 — документация [x]
- `CLAUDE.md` — правило про свёртку как уровень показа.
- `.business/история/` — рефлексия.
