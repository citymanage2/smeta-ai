# Сокращение формата ответа ИИ в ESTIMATE_FROM_LIST (оптимизация output-токенов)

Дата: 2026-07-15
Ветка: `feature/estimate-output-trim`
Research: `thoughts/research/2026-07-15-estimate-output-trim.md`

## Проблема
Смета из перечня стоит ~$10. Output-токены (то, что пишет ИИ) — ~18% стоимости.
ИИ на каждую позицию echo-ит поля, которые сервис не использует, и пишет обязательную
развёрнутую фразу про НДС, которая почти никогда не попадает в Excel.

## Что реально используется из ответа ИИ (находка research)
Используются: `id, type, name, unit, work_price, material_price, sources`, `notes` — лишь fallback.
НЕ используются: `quantity`, `price_list_name` (Excel берёт оригинал / хардкод "Интернет").

## Решение (пункт 3 из плана оптимизации затрат)
Правка единственного источника — константы `PROMPT_ESTIMATE_FROM_LIST` (task_processor.py:274),
которая используется в обоих Claude-вызовах сметы.

1. Убрать из требуемой JSON-схемы ответа `quantity` и `price_list_name` (балласт).
2. Сжать `notes`: сохранить ПРАВИЛО «цены всегда без НДС, при необходимости делить на 1.22»,
   но заменить обязательную фразу «Цена без НДС: X / Цена с НДС: Z» на короткую пометку
   только когда НДС реально вычитался (иначе пусто). Решение пользователя: «короткая пометка».
3. Оставить 3 источника (`sources`) — по решению пользователя, это и есть Excel-примечание.

## Что НЕ трогаем
- `name`, `type` в ответе — нужны для сохранения в кеш (`save_to_cache`) и как якорь id↔цена.
- Логику разбора JSON, сборку Excel, ретраи — не меняем.
