# Plan: Редизайн карточек проектов + удаление в корзину

## Статус: [x] Реализован полностью

## Задача
Переработать вкладку «Проекты»: убрать кнопки xlsx/PDF из карточки, добавить подробную информацию и кнопку удаления проекта.

## Фазы

### [x] Фаза 1 — Backend: soft delete проекта
- Добавлен `deleted_at` в модель `Project`
- Создана миграция `025_add_deleted_at_to_projects.py`
- Endpoint `DELETE /projects/{id}` теперь делает soft delete (устанавливает `deleted_at = now()`)
- `GET /projects` фильтрует только активные (`deleted_at IS NULL`)
- Удалена зависимость от `get_admin_user` — удалять может любой авторизованный пользователь

### [x] Фаза 2 — Backend: виды задач в карточке
- Добавлены поля `task_type_counts: dict[str, int]` и `total_tasks: int` в `ProjectCardResponse` и `ProjectDetailResponse`
- Новый хелпер `_get_task_type_counts` — отдельный запрос GROUP BY project_id, task_type
- `total_tasks` считается через `func.count(Task.id)` в основном запросе

### [x] Фаза 3 — Frontend: новый дизайн карточки
- Убраны кнопки «↓ xlsx» и «↓ PDF»
- Добавлена сумма по сметам справа вверху карточки (крупно, с подписью)
- Добавлен блок «Виды задач» — список `TASK_TYPE_LABELS[type]` с количеством справа
- Добавлена кнопка «Удалить проект» с модальным окном подтверждения
- Модалка показывает название проекта и количество задач, которые уйдут в корзину

## Итог
Реализован полностью. Миграция 025 применится автоматически при следующем деплое.
