# Методология: Ручная оптимизация выбранных позиций

**Дата:** 2026-04-23  
**Статус:** Согласовано  
**Контекст:** Фаза 6.6. Пользователь вручную отмечает галочками строки в гриде и запрашивает оптимизацию только для них.

---

## Цель

Дать пользователю возможность проверить любые конкретные позиции сметы в любой момент — независимо от прохождения основных шагов 1–4.

---

## Три направления анализа

| Направление | Код | Описание |
|---|---|---|
| Технологическая замена | `technology` | Та же работа, другим способом — дешевле |
| Замена материала | `material` | Аналог с теми же характеристиками — дешевле |
| Поиск цен в интернете | `price_search` | Актуальные цены на материал/работу с указанием источников |

---

## Входные данные

- **Выбранные строки** (`row_ids`) из текущей активной версии
- **Версия** (`version_id`) — текущая активная версия в гриде

---

## Один запрос — один промпт (без чанкинга)

Пользователь сам выбирает строки, их обычно немного (1–20). Чанкинг не нужен — запрос синхронный.

---

## Промпт Claude

**Вход:** JSON выбранных строк `EstimateRow[]`

```
Ты — опытный инженер-сметчик и снабженец.

Тебе переданы конкретные позиции сметы, выбранные пользователем для анализа.
Для каждой позиции найди возможности снизить стоимость.

Три направления анализа:

1. ТЕХНОЛОГИЧЕСКАЯ ЗАМЕНА — та же работа, но другим способом.
   Более производительным, механизированным или с меньшими трудозатратами.
   Конечный результат для заказчика не должен измениться.
   Посчитай новую стоимость и экономию в рублях и процентах.
   Укажи расценку ФСНБ/ГЭСН для новой технологии.

2. ЗАМЕНА МАТЕРИАЛА — другой материал с теми же техническими характеристиками и функцией.
   Укажи конкретную альтернативу (наименование, марка, ГОСТ).
   Посчитай новую стоимость и экономию в рублях и процентах.

3. ПОИСК ЦЕН В ИНТЕРНЕТЕ — найди актуальные рыночные цены на данный материал или работу.
   Укажи конкретные источники: название поставщика/сайта, URL если знаешь, цену и дату актуальности.
   Сравни с ценой в смете — дороже или дешевле рынка.

Для направлений 1 и 2 применяй критерии перед тем как предлагать:
- Конечный результат для заказчика не изменится
- Соответствует ГОСТ/СП/ФСНБ
- Экономия > 5% от стоимости позиции

Если ни одно из трёх направлений не даёт результата для конкретной позиции — напиши об этом явно.

Верни JSON:
{
  "proposals": [

      "what_changes": "Что именно меняется",

      "cost_before": число или null,

      "savings_pct": число или null,

      "norm_reference": "ГЭСН/ФСНБ/ГОСТ код или null",
      "price_sources": [
        {
          "supplier": "Название поставщика",
          "url": "URL или null",
          "price": число,
          "unit": "ед. изм.",
```

## UX

### Кнопка в EstimateGrid

Показывается только если выбрана хотя бы одна строка чекбоксом:
```
[☑ Предложить варианты оптимизации (3 строки)]
```

Состояния: `active` (есть выбранные строки) | `running` (spinner) | скрыта (нет выбранных)

### Панель результатов

Та же `OptimizationProposalsPanel` что у основных шагов.

Для `price_search` предложений:
```
┌─ Результаты поиска цен ─────────────────────────────────────┐
│  Арматура А500 12мм  •  В смете: 85 руб/кг                  │
│  ──────────────────────────────────────────────────────────  │
│  • Северсталь Дистрибуция — 76 руб/кг  (сайт: ...)          │
│  • Евраз Металл Инпром — 78 руб/кг    (сайт: ...)           │
│  • Металлопрокат.ру — 74 руб/кг       (сайт: ...)           │
│  Вывод: цена в смете выше рынка на ~11%                      │
└─────────────────────────────────────────────────────────────┘
```

Предложения `price_search` не имеют кнопок «Принять/Отклонить» — они информационные, не меняют смету.
Предложения `technology` и `material` — стандартные кнопки «Принять / Отклонить», создают новую версию.

### Версия при принятии

Принятые предложения применяются к текущей активной версии. Создаётся новая версия с автоматическим именем:
```
version_display_name = f"Ручная оптимизация {N}"
version_label = "custom_N"
```
где N — порядковый номер ручных оптимизаций для данной задачи.

---

## Связи с другими шагами

Ручная оптимизация доступна **в любой момент** — не зависит от прохождения шагов 1–4. Работает с любой версией сметы, которая активна в гриде.
