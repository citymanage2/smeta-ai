# Spec: Soft Delete карточек канбана с восстановлением из корзины

**Дата:** 2026-05-24  
**Статус:** Approved

## Проблема

Сейчас удаление карточки в канбане — это жёсткое безвозвратное удаление: карточка и все её задачи уничтожаются из БД. Нет возможности восстановить случайно удалённую карточку.

## Цель

При удалении карточки в канбане — все задачи карточки перемещаются в корзину (soft delete). Из корзины можно восстановить карточку обратно в проект на ту же стадию (колонку), откуда была удалена. Карточку также можно удалить из корзины навсегда.

## Scope

**IN:**
- Soft delete карточки + всех её задач при нажатии «Удалить» в канбане
- Вкладка «Карточки» в `/trash` — список soft-deleted карточек
- Восстановление карточки из корзины → в проект, на исходную стадию, с задачами
- Перманентное удаление карточки из корзины
- Фильтрация soft-deleted карточек из GET `/projects/{id}/workflow-cards`

**OUT:**
- Очистка всей корзины карточек (не приоритет — нет в требованиях)
- Изменение поведения корзины задач (отдельная вкладка, как раньше)
- Восстановление отдельных задач из карточки (только карточка целиком)

## Критерии приёмки

1. Нажать «Удалить» на карточке → карточка исчезает из канбана; задачи в корзине задач **не появляются** как индивидуальные задачи (они привязаны к карточке)
2. Открыть `/trash` → вкладка «Карточки» → карточка видна с именем, стадией, проектом, датой удаления
3. Нажать «Восстановить» → карточка появляется в канбане проекта в той же колонке (list/completeness/estimate/optimization); задачи снова прикреплены к карточке
4. Нажать «Удалить навсегда» → карточка и задачи физически удаляются из БД
5. Перезагрузить страницу проекта после удаления карточки → карточка не появляется

## Ограничения

- Если проект был удалён до восстановления карточки — восстановление невозможно (404)
- WorkflowCard.deleted_at — новое поле, требует миграции (027)
- Задачи карточки не должны появляться в корзине задач как отдельные элементы (они управляются через карточку)
