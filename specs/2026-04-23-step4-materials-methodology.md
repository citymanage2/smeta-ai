# Методология: Шаг 4 — Оптимизация по материалам

**Дата:** 2026-04-23  
**Статус:** Согласовано  
**Контекст:** Четвёртый шаг модуля оптимизации. Работает с Версией 3 (результат Шага 3).

---

## Цель

Найти позиции, где CityManage может купить тот же или эквивалентный материал **дешевле** — без изменения конечного результата для заказчика.

Два направления анализа:

| Направление | Код | Описание |
|---|---|---|
| Замена материала | `material` | Другой материал с теми же характеристиками и функцией |
| Закупочная оптимизация | `procurement` | Тот же материал, но дешевле за счёт условий закупки |

---

## Входные данные

- **Версия 3** (зафиксированная из Шага 3) — список строк `EstimateRow[]`
- **Файл ТЗ** (если загружен) — Claude проверит, не прописаны ли конкретные бренды/марки

## ABC-анализ материалов (код, без AI, мгновенно)

Шаг 4 делает **свой отдельный ABC** — только по строкам `type: 'material'`.  
ABC Шага 3 был по работам, этот — по материалам. Это два разных расчёта.

**Алгоритм:**
1. Отбираем строки с типом `material`
2. Считаем суммарную стоимость всех материалов
3. Сортируем материалы по убыванию `cost`
4. Считаем накопленный итог от суммы материалов, присваиваем группу:
   - **Группа A** — материалы, формирующие 0–80% суммы материалов → идут в анализ Claude
   - **Группа B** — материалы, формирующие 80–95% суммы материалов → не анализируются
   - **Группа C** — материалы, формирующие 95–100% суммы материалов → не анализируются
5. Поле `abc_group` заполняется у строк типа `material` (сохраняется в БД)

**Результат отображается в UI сразу:**
```
Группа А: 5 позиций  •  1 240 000 ₽  •  81% суммы материалов  →  анализируются
Группа Б: 8 позиций  •  210 000 ₽   •  14% суммы материалов  →  не анализируются
Группа В: 14 позиций •  75 000 ₽    •   5% суммы материалов  →  не анализируются
```

## Промпт Claude

**Вход:** JSON материальных позиций группы A (строки `type: 'material'`) + файл ТЗ если есть

```
Ты — опытный инженер-сметчик и снабженец.

Тебе переданы материальные позиции сметы группы А — наиболее дорогостоящие материалы (около 80% суммы материалов).
Найди возможности снизить стоимость материалов при том же конечном результате для заказчика.

Два направления анализа:

1. ЗАМЕНА МАТЕРИАЛА — другой материал с теми же техническими характеристиками и функцией.
   Примеры:
   - Кирпич М100 → Газобетон D500 (те же звукоизоляция и нагрузка, 25–35% дешевле)
   - Knauf Rotband → Отечественный аналог с теми же характеристиками по ГОСТ (15–40% дешевле)
   - Импортная арматура А500 → Отечественная А500 (те же ГОСТ-характеристики)
   - Гипсокартон Knauf → аналог ГКЛО отечественного производства

2. ЗАКУПОЧНАЯ ОПТИМИЗАЦИЯ — тот же материал, но условия закупки позволяют сэкономить.
   Варианты:
   - Объём достаточен для оптовой скидки у производителя (укажи порог объёма)
   - Есть местный поставщик с аналогичной продукцией (меньше транспорт)
   - Материал лучше брать напрямую у производителя, а не через дистрибьютора

Для каждого предложения по замене материала:
- Укажи конкретную альтернативу (наименование, марка, ГОСТ)
- Рассчитай новую стоимость и экономию в рублях и процентах
- Проверь 5 критериев перед тем, как предлагать:
  1. Функциональный результат для заказчика не изменится
  2. Материал соответствует ГОСТ/ТУ/СП
  3. ТЗ тендера не прописывает конкретный бренд или марку (если ТЗ не передан — отметить «требует проверки»)
  4. Материал реально доступен (не экзотика, есть в стандартных поставках)
  5. Экономия > 5% от стоимости позиции

Для закупочной оптимизации — не меняй строку сметы, только сформулируй рекомендацию закупщику.

Не предлагай замены, в которых не уверен.
```

### Закупочные рекомендации

Отображаются отдельным блоком под заменами. Не имеют кнопок «Принять/Отклонить» — смету не меняют. При скачивании Excel выводятся в отдельный столбец «Рекомендации закупщику» напротив соответствующей строки материала. При фиксации Версии 4 записываются в `optimization_proposals` со статусом `procurement_note`.

## Решения по UX

1. **Анализируется только Группа A материалов.** Группы B и C не анализируются — они несущественны по сумме.

2. **Материалы всегда отдельными строками.** В наших сметах материалы выделены в отдельные строки `type: 'material'`. Строки типа `work` не содержат `price_material` — у них это поле всегда 0 или null. Шаг 4 анализирует исключительно строки `type: 'material'`.

3. **Закупочные рекомендации** — в скачиваемом Excel выводятся отдельным столбцом «Рекомендации закупщику» напротив соответствующей строки материала.
