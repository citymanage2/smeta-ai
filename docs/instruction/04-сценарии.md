# 4. Алгоритмы работы в сервисе

> Версия документа: 1.0 | Дата: 2026-05-22

Каждый сценарий — это полная цепочка действий для конкретной задачи тендерной подготовки. Выберите нужный сценарий в зависимости от того, что у вас есть на входе.

---

## Сценарий А. Смета из Гранд-Сметы заказчика (полный цикл)

**Когда использовать:** у вас есть файл Гранд-Сметы от заказчика (Excel, XML или PDF).

**Что понадобится:** файл Гранд-Сметы в формате `.xlsx`, `.xls`, `.xml` или `.pdf`.

---

### Шаг 1. Создать проект

1. На главной странице нажмите **«Создать проект»**.
2. Введите название тендера (кратко и однозначно).
3. Нажмите **«Создать»**.
> Откроется страница проекта с пустым списком задач.

---

### Шаг 2. Получить перечень из Гранд-Сметы

1. Нажмите **«Новая задача»** → выберите **«Перечень из Гранд-Сметы»**.
2. Загрузите файл заказчика.
3. Нажмите **«Запустить»**.
> Статус изменится на «Обрабатывается». Подождите 2–7 минут до статуса «Готово».

**Что проверить в результате:**
- [ ] Количество позиций примерно совпадает с файлом заказчика
- [ ] Нет явно лишних строк (заголовки разделов, итоговые строки попали в перечень)
- [ ] Есть оба типа позиций: работы и материалы

> Если список явно обрезан или в нём мусор — сообщите бизнес-ассистенту с примером исходного файла.

---

### Шаг 3. Проверить полноту перечня

1. Нажмите **«Новая задача»** → выберите **«Проверка полноты»**.
2. Система автоматически возьмёт перечень из шага 2.
3. Нажмите **«Запустить»**.
> Статус «Обрабатывается» → 3–8 минут → «Готово».

**Что проверить в результате:**
- [ ] Появились новые позиции — это нормально, ИИ добавил недостающие материалы по ГЭСН
- [ ] В столбце «Примечания» у добавленных позиций — обоснование (ссылка на ГЭСН)
- [ ] Добавленные позиции логичны (например, к работе «Кладка кирпича» добавился «Раствор цементный»)

> Если добавлено слишком много явно лишних позиций — сообщите бизнес-ассистенту.

---

### Шаг 4. Рассчитать смету

1. Нажмите **«Новая задача»** → выберите **«Смета из перечня»**.
2. Система автоматически возьмёт перечень из шага 3.
3. Нажмите **«Запустить»**.
> 3–10 минут → статус «Готово».

**Что проверить в результате:**
- [ ] Итоговая сумма выглядит реалистично для данного типа и объёма работ
- [ ] Проверьте позиции со столбцом «Источник» = «Не найдено» — по ним нет цены
- [ ] Нет позиций с явно неверной ценой (например, 1 рубль за единицу сложной работы)

**Если есть позиции без цены:**
- Нажмите «Проставить пропущенные цены» — сервис сделает ещё одну попытку.
- Если цена так и не нашлась — сообщите бизнес-ассистенту с наименованием позиции.

---

### Шаг 5. Скачать и передать руководителю

1. Нажмите **«Скачать»** → сохраните файл `.xlsx`.
2. Перенесите данные в корпоративный шаблон CityManage.
3. Передайте руководителю отдела на проверку.

> Отправка заказчику — только после согласования руководителем.

## Сценарий Б. Смета из проектной документации (полный цикл)

**Когда использовать:** у вас есть PDF проекта (спецификации, ведомости, чертежи), но нет Гранд-Сметы.

**Что понадобится:** PDF проектной документации.

---

### Шаг 1–2. Создать проект и задачу «Перечень из проекта»

1. Создайте проект (см. Сценарий А, Шаг 1).
2. Нажмите **«Новая задача»** → выберите **«Перечень из проекта»**.
3. Загрузите PDF.
4. Нажмите **«Запустить»**.
> 5–15 минут → статус «Готово». Время зависит от объёма PDF.

**Что проверить в результате:**
- [ ] Позиции соответствуют спецификациям из проекта
- [ ] Объёмы заполнены (или отмечено, почему объём нельзя определить)
- [ ] В «Примечаниях» — ссылки на листы проекта

---

### Шаги 3–5. Проверка полноты → Смета → Скачать

Далее — аналогично Сценарию А, Шаги 3–5.

---

## Сценарий В. Расценить готовый перечень

**Когда использовать:** перечень работ и материалов уже есть в Excel (например, подготовлен вручную или перенесён из другого источника).

**Что понадобится:** Excel-файл с перечнем в стандартном формате (столбцы: Тип, Наименование, Ед. изм., Кол-во).

---

### Шаги

1. Создайте проект.
2. Нажмите **«Новая задача»** → выберите **«Смета из перечня»**.
3. Загрузите Excel с перечнем.
4. Нажмите **«Запустить»**.
> 3–10 минут → статус «Готово».

5. Проверьте результат (чеклист — см. Сценарий А, Шаг 4).
6. Скачайте и передайте руководителю.

---

## Сценарий Г. Оптимизация сметы

**Когда использовать:** у вас есть готовая смета (своя или заказчика), нужно проверить состав, скорректировать объёмы или цены перед тендером.

**Что понадобится:** Excel-смета.

---

### Шаги

1. Создайте задачу **«Оптимизация сметы»** в нужном проекте.
2. Загрузите Excel-смету. Опционально — загрузите смету заказчика для сравнения.
3. Нажмите **«Запустить»**.
> Откроется интерактивный редактор со структурированными строками.

4. В редакторе:
   - Проверьте каждую строку: тип, наименование, количество, цену.
   - Нажмите на строку, чтобы отредактировать значение.
   - Система пересчитывает итог в реальном времени.
   - История изменений сохраняется — можно откатить любое действие.

5. Когда результат устраивает — скачайте итоговый Excel.
6. Передайте руководителю на проверку.

> Редактор оптимизации не заменяет шаги «Перечень» и «Проверка полноты» — он предназначен для финальной корректировки уже сформированной сметы.

---

## Справка: что значит «Источник» в смете

| Значение в столбце «Источник» | Смысл |
|---|---|
| Прайс (точное) | Цена найдена в корпоративном прайсе по точному совпадению названия |
| Прайс (похожее) | Цена найдена по смыслу — проверьте, что позиция корректна |
| ИИ / Рынок | Цена запрошена у ИИ, основана на рыночных данных по Екатеринбургу |
| Не найдено | Цена не определена — нужно заполнить вручную или сообщить администратору |
