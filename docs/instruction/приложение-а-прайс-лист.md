# Приложение А. Управление прайс-листом

> Только для администратора (бизнес-ассистента)
> Версия документа: 1.0 | Дата: 2026-05-22

---

## Что такое корпоративный прайс-лист

Прайс-лист — база корпоративных расценок CityManage. Сервис использует его при расчёте смет: сначала ищет точное совпадение, затем — похожее по смыслу.

Прайс содержит два раздела:
- **Работы** — наименование + единица измерения + цены от подрядчиков
- **Материалы** — наименование + единица измерения + цена

---

## Как искать в прайсе

На странице прайс-листа используйте поиск по наименованию. Фильтрация — по типу (работы / материалы).

---

## Добавить одну позицию вручную

1. Перейдите в раздел **«Прайс-лист»**.
2. Нажмите **«Добавить позицию»**.
3. Заполните: тип (работа / материал), наименование, единица измерения, цена.
4. Нажмите **«Сохранить»**.
> Система автоматически создаст embedding для новой позиции — это займёт до 1 минуты. После этого позиция начнёт применяться в новых задачах.

**Важно при выборе наименования:**
- Пишите полное наименование без сокращений
- Используйте те же термины, что применяются в сметах заказчиков
- Единица измерения — стандартная (м², м³, шт, п.м., кг, т)

---

## Загрузить прайс из Excel

Если нужно добавить много позиций сразу:

1. Скачайте шаблон Excel (кнопка **«Скачать шаблон»** на странице прайс-листа).
2. Заполните по столбцам: Тип | Наименование | Ед. изм. | Цена.
3. Нажмите **«Загрузить файл»** и выберите заполненный Excel.
> Позиции импортируются. Статус embedding: «Ожидание» → «Готово» (занимает несколько минут).
> Если у позиции статус «Ошибка» — проверьте заполнение строки.

---

## Обновить цену существующей позиции

1. Найдите позицию в прайс-листе.
2. Нажмите **«Редактировать»**.
3. Измените цену.
4. Нажмите **«Сохранить»**.
> Новая цена применяется в задачах, запущенных после сохранения.

---

## Что делать при обращении менеджера «цена не найдена»

1. Получите от менеджера точное наименование позиции (как оно написано в смете заказчика).
2. Найдите рыночную цену по Екатеринбургу (запросите у подрядчика или найдите в открытых источниках).
3. Добавьте позицию в прайс (вручную или через Excel).
4. Сообщите менеджеру — он сможет перезапустить задачу «Смета из перечня».

---

## Как работает поиск цен (для понимания)

Когда сервис расценивает перечень, он ищет цену в три шага:

1. **Точное совпадение** — нормализованное название совпадает с прайсом (быстро, надёжно)
2. **Поиск по смыслу** — embedding-сравнение, порог сходства 93% (хорошо для синонимов)
3. **Запрос к ИИ** — если ничего не нашлось, ИИ ищет рыночную цену по Екатеринбургу и указывает 3 источника

Результат шага 3 — приблизительный. Рекомендуется добавлять такие позиции в прайс после проверки цены.
