## Быстрый старт

> Если вы открываете Сервис смет впервые — следуйте этим шагам.

**1.** Войдите в сервис. Логин и пароль — у бизнес-ассистента.

**2.** Нажмите **«Создать проект»**. Введите название тендера кратко и однозначно.

**3.** Нажмите **«Новая задача»** → выберите **«Перечень из Гранд-Сметы»**. Загрузите файл заказчика. Нажмите **«Запустить»**. Дождитесь статуса «Готово».

**4.** Создайте задачу **«Проверка полноты»** → запустите → дождитесь «Готово».

**5.** Создайте задачу **«Смета из перечня»** → запустите → дождитесь «Готово».

**6.** Откройте результат, проверьте итоговую сумму и позиции без цены. Скачайте `.xlsx`.

**7.** Передайте руководителю отдела на проверку перед отправкой заказчику.

## 1. Назначение сервиса

### Что делает Сервис смет

**Сервис смет** — внутренний инструмент CityManage для подготовки строительных смет к тендерам. Он извлекает позиции из документов заказчика, проверяет полноту по нормативам, проставляет цены из корпоративного прайса и готовит расценённую смету в Excel.

Сервис работает на основе искусственного интеллекта. **Результат всегда требует проверки менеджером** перед передачей руководителю и отправкой заказчику.

### Что умеет сервис

| Задача | Что подаёте на вход | Что получаете | Типичное время |
|---|---|---|---|
| Перечень из Гранд-Сметы | Excel / PDF / XML Гранд-Сметы заказчика | Excel с перечнем работ и материалов | 2–7 мин |
| Перечень из проекта | PDF проектной документации | Excel с перечнем и объёмами | 5–15 мин |
| Проверка полноты | Перечень из предыдущего шага | Перечень с добавленными позициями по ГЭСН | 3–8 мин |
| Смета из перечня | Проверенный перечень | Excel-смета с ценами и итоговой суммой | 3–10 мин |
| Оптимизация сметы из сервиса | Смета, рассчитанная в сервисе (шаг 3) | Онлайн-редактор: смета разбита по позициям, обогащена нормами ГЭСН, доступна правка любой строки, пересчёт итога в реальном времени, история изменений с откатом, скачать итоговый Excel | Ручная работа |
| Оптимизация сметы от сметчиков | Excel-смета, подготовленная сметчиками CityManage; опционально — смета заказчика для сравнения | Сервис разбирает смету на версии: V0 — исходная (неизменна), V1 — смета заказчика (если загружена). Онлайн-редактор с обогащением ГЭСН, сравнением версий, правкой позиций и выбором финальной версии для скачивания | Ручная работа |
| Сводная себестоимость | Рассчитанные сметы проекта (формируется автоматически) | Сводная таблица на странице проекта: себестоимость → наценка → итоговая цена клиенту. Один лист на каждый раздел проекта + сводный лист. Наценку и коэффициенты можно менять. Скачать Excel | Автоматически + правка коэффициентов |

**Как работает оптимизация — подробно:**

Оптимизация — единственный режим с ручным редактированием. Всё остальное в сервисе делает ИИ автоматически; здесь вы работаете со сметой руками в онлайн-редакторе.

**Стадии:**

1. **Загрузка и разбор.** Сервис разбирает Excel-смету на строки: каждая строка — это работа или материал с полями «наименование», «единица», «количество», «цена работы», «цена материала», «итого». Исходная смета сохраняется как версия **V0 «Исходная»** — она никогда не меняется, это точка отсчёта.

2. **Загрузка сметы заказчика (опционально).** Если загружаете второй файл — смету заказчика — она сохраняется как версия **V1 «Заказчик»**. Это позволяет видеть обе сметы рядом и сравнивать позиции.

3. **Обогащение нормами ГЭСН.** Для каждого материала в смете сервис определяет нормативный расход по ГЭСН — сколько единиц материала требуется на одну единицу соответствующей работы. Например: к работе «Кладка кирпича, 1 м³» норма кирпича — 400 шт. Это позволяет проверить, не занижено ли количество материалов.

4. **Онлайн-редактор.** Открывается таблица со всеми позициями сметы. Вы можете:
   - Изменить цену или количество любой позиции — итог пересчитывается в реальном времени.
   - Исключить или добавить позицию.
   - Сравнить свою смету со сметой заказчика (если загружена) прямо в интерфейсе.
   - Откатить любое изменение — история правок сохраняется полностью.

5. **Выбор итоговой версии.** После редактирования выбираете, какую версию скачать: исходную (V0), смету заказчика (V1, если была загружена) или отредактированную версию. Скачиваете Excel и передаёте руководителю.

### Что сервис НЕ делает

- Не отправляет документы заказчику — это делает менеджер.
- Не гарантирует 100% точность: ИИ может пропустить позицию, неверно определить объём или не найти цену. **Проверка обязательна.**
- Не принимает решение об участии в тендере — это остаётся за руководителем.

### Как устроен процесс

```
Документ заказчика
       ↓
[1.1] Перечень из Гранд-Сметы  или  [1.2] Перечень из проекта
       ↓
[2] Проверка полноты
       ↓
[3] Смета из перечня
       ↓
[4.1] Оптимизация сметы из сервиса  или  [4.2] Оптимизация сметы от сметчиков
       ↓
[5] Сводная себестоимость: себестоимость → наценка → цена клиенту
       ↓
Скачать Excel → Передать руководителю → Отправить заказчику
```

Не обязательно проходить все шаги. Если перечень уже готов — начните с шага 3.

### Роли в сервисе

| Роль | Кто | Что может делать |
|---|---|---|
| Менеджер | Сотрудник отдела продаж | Создавать проекты и задачи, работать со своими задачами, скачивать результаты |
| Руководитель отдела | Руководитель отдела продаж | То же + видит все задачи, проверяет и согласует сметы |
| Администратор | Бизнес-ассистент | Полный доступ: управление пользователями, прайс-лист, все задачи |

### Важно об ошибках ИИ

Сервис использует ИИ для обработки документов. ИИ хорошо работает с типовыми форматами, но может ошибаться в нестандартных ситуациях.

**Типичные ситуации, требующие внимания:**

- Позиция написана нестандартно или сокращена → сервис мог не распознать
- Позиция помечена «Источник: Не найдено» → цена не нашлась в прайсе
- PDF — скан низкого качества → часть текста могла не распознаться

**Правило:** перед передачей руководителю — всегда проверяйте итоговую сумму и позиции без цены.

## 2. Доступ к сервису

### Как получить доступ

Доступ выдаёт **бизнес-ассистент**. Обратитесь к нему с запросом — он создаст учётную запись и передаст логин и пароль.

### Вход в сервис

**1.** Откройте адрес сервиса в браузере (уточните у бизнес-ассистента).

**2.** Введите логин (email) и пароль.

**3.** Нажмите **«Войти»**. Откроется главная страница со списком ваших проектов.

### Если не получается войти

| Ситуация | Что делать |
|---|---|
| Не помните пароль | Напишите бизнес-ассистенту — сбросит пароль |
| Сервис не открывается | Проверьте интернет; если не помогло — напишите бизнес-ассистенту |
| Логин не найден | Учётная запись ещё не создана — напишите бизнес-ассистенту |

### Правила безопасности

- Не передавайте логин и пароль коллегам — у каждого своя учётная запись.
- Не сохраняйте пароль в общедоступных местах (заметки, мессенджеры).
- Если подозреваете, что данные скомпрометированы — немедленно сообщите бизнес-ассистенту.

## 3. Правила работы

### 3.1 Общие правила

**Один тендер — один проект.** Не смешивайте задачи по разным тендерам в одном проекте.

**Как называть проект.** Свободная форма — главное, чтобы через неделю было понятно, о чём речь.

- Хорошо: «ООО Альфа — благоустройство ул. Ленина, май 2026»
- Хорошо: «МКУ ДЕЗ — капремонт кровли ул. Садовая 12»
- Плохо: «Тендер 1», «Смета», «Новый проект»

**Ответственность за результат.** Сервис — вспомогательный инструмент. Финальную ответственность за корректность сметы несёт менеджер и руководитель отдела.

**Обязательное согласование.** Перед отправкой сметы заказчику — передайте руководителю отдела на проверку. Самостоятельная отправка без согласования не допускается.

### 3.2 Поддерживаемые форматы файлов

| Тип задачи | Принимаемые форматы |
|---|---|
| Перечень из Гранд-Сметы | `.xlsx`, `.xls`, `.xml`, `.pdf` |
| Перечень из проекта | `.pdf` |
| Смета из перечня | `.xlsx` |
| Оптимизация сметы | `.xlsx` |

> Формат `.gsn` не поддерживается — экспортируйте из Гранд-Сметы в `.xlsx` или `.xml` перед загрузкой.
> Максимум 10 файлов за раз, не более 20 МБ на файл.

**Как готовить файлы:**
- Гранд-Смета в `.gsn` → открыть в программе и экспортировать в Excel/XML.
- PDF-скан низкого качества → по возможности используйте текстовый PDF.
- Excel с нестандартными объединёнными ячейками → возможны ошибки парсинга.

### 3.3 Статусы задач

| Статус | Что означает |
|---|---|
| Ожидание | Задача поставлена в очередь |
| Обрабатывается | ИИ работает с файлом |
| Готово | Результат доступен для просмотра и скачивания |
| Ошибка | Задача не выполнена — см. раздел 5 |
| Отменено | Задача остановлена пользователем |

### 3.4 Работа с ценами

Сервис ищет цены в три шага:
1. Точное совпадение с корпоративным прайсом
2. Поиск по смыслу (похожие наименования)
3. Запрос к ИИ: рыночная цена по Екатеринбургу

**Если позиция без цены или с явно неверной ценой:**

- **Вариант А** — нажмите кнопку обновления цены рядом с позицией в таблице.
- **Вариант Б** — нажмите **«Проставить пропущенные цены»** — сервис попробует заполнить все позиции без цены.
- **Вариант В** — если цена так и не нашлась, сообщите бизнес-ассистенту с наименованием позиции. После добавления в прайс можно перезапустить задачу «Смета из перечня».

### 3.5 Обязанности сотрудников

Все сотрудники, работающие с сервисом, обязаны:

- **Сообщать бизнес-ассистенту об ошибках** — некорректные позиции, неверные цены, зависшие задачи.
- **Вносить предложения по улучшению логики** — если видите, что можно сделать лучше, напишите бизнес-ассистенту.
- **Передавать смету на проверку** руководителю перед каждой отправкой заказчику.
- **Не передавать учётные данные** другим сотрудникам.

## 4. Алгоритмы работы в сервисе

---

### 4.1 Перечень из Гранд-Сметы

**Когда использовать:** есть файл Гранд-Сметы от заказчика.

**Что понадобится:** файл в формате `.xlsx`, `.xls`, `.xml` или `.pdf`.

**Шаги:**

1. На главной странице нажмите **«Создать проект»**. Введите название тендера. Нажмите **«Создать»**.
2. Нажмите **«Новая задача»** → выберите **«Перечень из Гранд-Сметы»**.
3. Загрузите файл заказчика. Нажмите **«Запустить»**.
4. Дождитесь статуса **«Готово»** (2–7 минут). Откройте результат.

**Что проверить в результате:**
- [ ] Количество позиций примерно совпадает с файлом заказчика
- [ ] Нет явно лишних строк (заголовки разделов, итоговые строки)
- [ ] Есть оба типа позиций: работы и материалы

> Если список явно обрезан или содержит мусор — сообщите бизнес-ассистенту с примером исходного файла.

---

### 4.2 Перечень из проекта

**Когда использовать:** есть PDF проекта (спецификации, ведомости, чертежи), но нет Гранд-Сметы.

**Что понадобится:** PDF проектной документации.

**Шаги:**

1. Создайте проект.
2. Нажмите **«Новая задача»** → выберите **«Перечень из проекта»**.
3. Загрузите PDF. Нажмите **«Запустить»**.
4. Дождитесь статуса **«Готово»** (5–15 минут). Откройте результат.

**Что проверить в результате:**
- [ ] Позиции соответствуют спецификациям проекта
- [ ] Объёмы заполнены (или отмечено, почему нельзя определить)
- [ ] В «Примечаниях» есть ссылки на листы проекта

---

### 4.3 Проверка полноты перечня

**Когда использовать:** после получения перечня (шаги 4.1 или 4.2) — перед расчётом сметы.

**Шаги:**

1. Нажмите **«Новая задача»** → выберите **«Проверка полноты»**.
2. Система автоматически возьмёт перечень из предыдущего шага.
3. Нажмите **«Запустить»**.
4. Дождитесь статуса **«Готово»** (3–8 минут). Откройте результат.

**Что проверить в результате:**
- [ ] Появились новые позиции — это нормально, ИИ добавил материалы по ГЭСН
- [ ] У добавленных позиций в «Примечаниях» есть обоснование (ссылка на ГЭСН)
- [ ] Добавленные позиции логичны по контексту (к «кладке кирпича» добавился «раствор», но не «арматура для перекрытий»)

> Если добавлено слишком много явно лишних позиций — сообщите бизнес-ассистенту.

---

### 4.4 Смета из перечня

**Когда использовать:** после проверки полноты или если перечень уже готов.

**Шаги:**

1. Нажмите **«Новая задача»** → выберите **«Смета из перечня»**.
2. Система возьмёт перечень из предыдущего шага автоматически. Если перечень свой (не из сервиса) — загрузите файл `.xlsx`.
3. Нажмите **«Запустить»**.
4. Дождитесь статуса **«Готово»** (3–10 минут). Откройте результат.

**Что проверить в результате:**
- [ ] Итоговая сумма выглядит реалистично для данного объёма работ
- [ ] Проверьте позиции со значением «Не найдено» в столбце «Источник» — по ним нет цены
- [ ] Нет позиций с явно неверной ценой (например, 1 рубль за единицу сложной работы)
- [ ] Позиции с «Источник: Прайс (похожее)» — проверьте, что сопоставление корректно

**Если есть позиции без цены:**
- Нажмите **«Проставить пропущенные цены»** — ещё одна попытка.
- Если цена так и не нашлась — сообщите бизнес-ассистенту с наименованием позиции для добавления в прайс.

**Скачать смету:** нажмите **«Скачать»** → сохраните `.xlsx`. При необходимости перенесите данные в корпоративный шаблон CityManage.

---

### 4.5 Оптимизация сметы, созданной в сервисе

**Когда использовать:** нужно скорректировать состав, объёмы или цены в смете, уже рассчитанной в сервисе.

**Шаги:**

1. В проекте нажмите **«Новая задача»** → выберите **«Оптимизация сметы»**.
2. Система возьмёт готовую смету из предыдущего шага. Нажмите **«Запустить»**.
3. Откроется интерактивный редактор со структурированными строками.
4. В редакторе:
   - Нажмите на строку, чтобы отредактировать значение (наименование, количество, цену).
   - Итоговая сумма пересчитывается в реальном времени.
   - История изменений сохраняется — любое действие можно откатить.
5. Когда результат устраивает — нажмите **«Скачать»**.
6. Передайте руководителю на проверку.

---

### 4.6 Оптимизация сметы от сметчиков компании

**Когда использовать:** есть готовая смета, подготовленная сметчиками CityManage (Excel), и нужно проверить состав или скорректировать цены перед тендером.

**Что понадобится:** Excel-смета от сметчиков. Опционально — смета заказчика для сравнения.

**Шаги:**

1. Создайте проект (или откройте существующий).
2. Нажмите **«Новая задача»** → выберите **«Оптимизация сметы»**.
3. Загрузите Excel-смету от сметчиков. При необходимости загрузите смету заказчика вторым файлом.
4. Нажмите **«Запустить»**.
5. Откроется интерактивный редактор. Сервис структурирует смету и обогатит нормативами ГЭСН (расходы материалов на единицу работы).
6. Проверьте и скорректируйте позиции в редакторе.
7. Скачайте итоговый Excel. Передайте руководителю на проверку.

**Что проверить перед сохранением:**
- [ ] Итоговая сумма соответствует ожиданиям
- [ ] Нормы ГЭСН выглядят корректно для каждого вида работы
- [ ] Позиции, которые вы изменили, отражены верно

---

### Справка: что значит «Источник» в смете

| Значение | Смысл |
|---|---|
| Прайс (точное) | Цена найдена по точному совпадению названия — надёжно |
| Прайс (похожее) | Цена найдена по смыслу — проверьте корректность сопоставления |
| ИИ / Рынок | Цена запрошена у ИИ на основе рыночных данных по Екатеринбургу — приблизительно |
| Не найдено | Цена не определена — нужно заполнить или сообщить администратору |

---

### 4.7 Сводная себестоимость проекта

**Когда использовать:** когда все сметы по проекту рассчитаны и нужно увидеть итоговую себестоимость, задать наценку и получить цену для клиента — одним документом.

**Где находится:** на странице проекта, внизу или в боковой панели — раздел «Сводная себестоимость».

---

**Как устроена сводная:**

Сводная себестоимость формируется автоматически из всех расценённых смет проекта. Структура:

- **Один лист = один раздел проекта** (каждая смета / этап работ — отдельный лист).
- **Лист «Сводная»** — агрегированный итог по всем разделам.

Каждый раздел и сводный лист содержат три уровня расчёта:

| Показатель | Что это |
|---|---|
| **Себестоимость** | Итоговая сумма сметы — стоимость работ и материалов по прайсу |
| **Наценка** | Рассчитывается через коэффициент, который вы задаёте вручную |
| **Итоговая цена для клиента** | Себестоимость + наценка — сумма, которую предъявляете заказчику |

---

**Как работать со сводной:**

**1.** Откройте проект. Перейдите в раздел **«Сводная себестоимость»**.
> Таблица строится автоматически на основе всех рассчитанных смет проекта. Если смета ещё не рассчитана — раздел покажет незаполненные строки по этому разделу.

**2.** Проверьте себестоимость по каждому разделу — цифры берутся напрямую из итогов смет.

**3.** Задайте коэффициент наценки для каждого раздела (или единый для всего проекта). Сервис автоматически пересчитает наценку и итоговую цену.
> Коэффициент вводится вручную. Например: 1.15 — наценка 15%, 1.20 — 20%.

**4.** Проверьте лист **«Сводная»** — итог по всем разделам: суммарная себестоимость, суммарная наценка, итоговая цена для клиента.

**5.** Нажмите **«Скачать Excel»** — файл содержит все листы (по разделам + сводный).

---

**Что проверить перед скачиванием:**
- [ ] Все разделы проекта присутствуют в сводной — нет пропущенных смет
- [ ] Себестоимость по каждому разделу совпадает с итогом соответствующей сметы
- [ ] Коэффициент наценки задан корректно
- [ ] Итоговая цена для клиента в листе «Сводная» выглядит реалистично

> Сводную себестоимость передайте руководителю вместе с основными сметами — это основа для принятия решения об участии в тендере.

---

### Чеклист проверки перед передачей руководителю

- [ ] Итоговая сумма выглядит реалистично для данного объёма и типа работ
- [ ] Нет позиций с нулевой или явно неверной ценой
- [ ] Нет позиций без цены (столбец «Источник» = «Не найдено»)
- [ ] Количество разделов совпадает с исходным документом заказчика
- [ ] Название проекта соответствует тендеру

> Если хотя бы один пункт не выполнен — устраните до передачи руководителю.

## 5. Поддержка

### По всем вопросам — бизнес-ассистент

Все вопросы, ошибки, предложения — через бизнес-ассистента.

**Что указывать в сообщении:**
- Название проекта и задачи
- Что произошло (кратко)
- Скриншот или пример некорректной позиции (если есть)

### Типичные проблемы и решения

| Ситуация | Что делать самостоятельно | Когда писать бизнес-ассистенту |
|---|---|---|
| Задача не переходит из «Обрабатывается» больше 20 минут | Обновите страницу, проверьте статус | Если статус не изменился — сразу |
| Задача завершилась со статусом «Ошибка» | Попробуйте запустить повторно | Если ошибка повторяется |
| Позиции в результате явно неверны | Сравните с исходным файлом | Сообщите с примером — для улучшения |
| Цена не найдена у нескольких позиций | Нажмите «Проставить пропущенные цены» | Если цена всё равно не нашлась — для добавления в прайс |
| Сервис не открывается | Проверьте интернет, попробуйте другой браузер | Если проблема сохраняется |
| Не помните пароль | — | Сразу — бизнес-ассистент сбросит |

### Как сообщить об ошибке эффективно

**Хорошее сообщение:**
> «Проект "МКУ ДЕЗ — кровля", задача "Перечень из Гранд-Сметы" от 21.05. В результате отсутствует раздел "Кровельные работы". В исходном файле он есть на листе "СМР", строки 45–78.»

**Плохое сообщение:**
> «Сервис не работает»

Чем точнее описание — тем быстрее исправление.

### Обязанности сотрудников

Все сотрудники обязаны:

- Сообщать бизнес-ассистенту о найденных ошибках.
- Вносить предложения по улучшению логики сервиса.

Ваши наблюдения напрямую влияют на качество инструмента.

## Приложение А. Управление прайс-листом (только для администратора)

### Что такое корпоративный прайс-лист

База корпоративных расценок CityManage. Используется при расчёте смет: сначала ищется точное совпадение, затем — похожее по смыслу. Два раздела: **Работы** и **Материалы**.

### Добавить позицию вручную

1. Перейдите в **«Прайс-лист»** → нажмите **«Добавить позицию»**.
2. Заполните: тип (работа / материал), наименование, единица измерения, цена.
3. Нажмите **«Сохранить»**.
> Система создаёт embedding для новой позиции — до 1 минуты. После этого позиция применяется в новых задачах.

**При выборе наименования:**
- Пишите полное название без сокращений
- Используйте те же термины, что встречаются в сметах заказчиков
- Единица измерения — стандартная: м², м³, шт, п.м., кг, т

### Загрузить прайс из Excel

1. Скачайте шаблон: кнопка **«Скачать шаблон»** на странице прайс-листа.
2. Заполните по столбцам: Тип | Наименование | Ед. изм. | Цена.
3. Нажмите **«Загрузить файл»** → выберите заполненный Excel.
> Статус embedding: «Ожидание» → «Готово» (несколько минут).
> Если у позиции статус «Ошибка» — проверьте заполнение строки.

### Обновить цену

1. Найдите позицию → нажмите **«Редактировать»**.
2. Измените цену → нажмите **«Сохранить»**.
> Новая цена применяется в задачах, запущенных после сохранения.

### Действия при обращении «цена не найдена»

1. Получите от менеджера точное наименование позиции (как написано в смете заказчика).
2. Найдите рыночную цену по Екатеринбургу.
3. Добавьте позицию в прайс.
4. Сообщите менеджеру — он перезапустит задачу «Смета из перечня».

### Как работает поиск цен

1. **Точное совпадение** — нормализованное название совпадает с прайсом (быстро, надёжно)
2. **Поиск по смыслу** — embedding-сравнение, порог сходства 93% (хорошо для синонимов)
3. **Запрос к ИИ** — если ничего не нашлось, ИИ ищет рыночную цену по Екатеринбургу, указывает 3 источника

Результат шага 3 — приблизительный. Рекомендуется добавлять такие позиции в прайс после проверки цены.
