## Что добавила Фаза 3 (коммит `045fed5`, ждёт сборки фронта)

В карточке расхождения теперь видно:

- число строк с каждой стороны — «60 (расчёт) против 58 (редактор)»;
- зелёное «итоги совпадают», когда деньги одинаковые;
- «состав строк совпадает — отличается только порядок» (считается сравнением
  отсортированных слепков строк) с советом оставить как в редакторе;
- до трёх примеров: что именно разошлось, с обеими величинами.

Ключевая функция: `describe_diff()` в
`backend/app/services/estimate_migration.py`.

## Следующие шаги

1. Дождаться сборки фронта, обновить страницу через `Cmd+Shift+R`, нажать
   «Проверить» заново.
2. Расхождения с пометкой «отличается только порядок» — «Оставить как в
   редакторе». Ничего не переписывается.
3. Три сметы с реальной разницей — посмотреть блок «Что разошлось» и решить с
   пользователем, чья сторона верна.
4. 54 недостающие версии — можно в любой момент, независимо от расхождений.
   Обязательно дать пользователю отметить активные тендеры.

## Грабли этой сессии (не наступать снова)

- **Деплой фронта дважды падал при успешной сборке.** В логах последняя строка
  `Build succeeded`, а статус — «Ошибка». Проверено: настройки деплоя верны
  (команда `npm run build`, директория сборки `/dist`, путь проекта
  `/frontend`, `VITE_API_BASE_URL` задана, ветка `main`); сборка идентична
  последнему успешному деплою — 1722 файла, 11 МБ. Позже деплой прошёл сам.
  Логов этапа после сборки панель не отдаёт.
- **Фронтенд — отдельное приложение Timeweb** (`stroyjoyka-frtontend`), пуш в
  `timeweb main` обновляет и его, и бэкенд, но у фронта своя сборка. Бэкенд по
  адресу `…twc1.net` отдаёт только API (корень уводит на `/docs`).
- **Миграции схемы идут сами** — web-контейнер на старте делает
  `alembic upgrade head`. Проверено на PostgreSQL 17: все 44 ревизии
  накатываются на чистую базу и идемпотентны.
- **Локально python 3.9**, поэтому в тестах и скриптах не использовать
  синтаксис 3.10+ (`str | None`).
- **Тестовые файлы должны импортировать `WorkflowCard`**, если трогают
  `document_locks`: иначе при запуске одного файла падает внешний ключ.
- **Не искать текст по всей странице в фронт-тестах**, когда карточек
  несколько — брать `within(card)`. На этом обожглись трижды.
